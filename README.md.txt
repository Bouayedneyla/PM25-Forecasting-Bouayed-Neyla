# PM2.5 Forecasting Using BiLSTM

## Project Description

This project focuses on forecasting PM2.5 air pollution levels using a Bidirectional Long Short-Term Memory (BiLSTM) neural network.

The project uses air quality and environmental data, including meteorological and atmospheric variables, to study and predict PM2.5 concentrations.

## Project Structure

- `data/`: Raw and processed datasets (not uploaded to GitHub).
- `notebooks/`: Jupyter notebooks.
- `src/`: Source code.
- `scripts/`: Python scripts.
- `folds/`: Dataset split configurations.
- `results/`: Model results and evaluation outputs.
- `figures/`: Generated visualizations.
- `reports/`: Project reports.
- `presentation/`: Presentation files.

## Dataset

The project uses air quality measurements combined with environmental variables.

The selected monitoring station for the initial preprocessing phase is CENCA1.

## Project Phases

- Phase 1: Data Exploration and Preprocessing.
- Phase 2: Model Training, Validation, Testing and Evaluation.
- Phase 3: Statistical Testing and Explainability.
